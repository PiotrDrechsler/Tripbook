# E2E Tests

End-to-end tests using Playwright.

## Structure

- `fixtures/` - Reusable test fixtures and helpers
- `page-objects/` - Page Object Model implementations
- `*.spec.ts` - Test files

## Running E2E Tests

```bash
# Run all E2E tests
npm run test:e2e

# Run E2E tests in UI mode
npm run test:e2e:ui

# Show test report
npm run test:e2e:report
```
